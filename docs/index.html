What this proves, and what it does not

The anchor proves the log head existed at that block. It does not prove the host was honest before anchoring, and entries the proxy never saw are not covered.

Warden enforces MCP tool calls routed through its proxy. Claude Code's own native tools are outside that boundary, so the demo switches them off. The contract is unaudited and testnet-only.
